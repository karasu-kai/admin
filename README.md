# KODO CO®

https://kodoco.com.au

Premium Australian skincare. Vite + React + TypeScript + Tailwind + Stripe Payment Links.

## Local dev

```bash
npm install
npm run dev
```

## Build site

```bash
npm run deploy:build
```

Built files go in `deploy/` — upload that folder to Hostinger `public_html`.
