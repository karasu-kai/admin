# Karasu Kai — admin

Brand assets and staging tooling for [Karasu Kai](https://www.karasukai.com.au).

## Yatagarasu crow mark

Anime-styled **three-legged crow** (faces left) for the empty crow slot on the main site.

| Asset | Use |
|-------|-----|
| `brand/assets/yatagarasu-anime.png` | Full master |
| `brand/assets/yatagarasu-anime-1024.png` | Web / hero |
| `brand/assets/yatagarasu-anime-512.png` | Crow slot / nav |
| `brand/index.html` | Preview with wordmark |
| `brand/snippet.html` | Drop-in markup |

### Preview

```bash
cd brand && python3 -m http.server 8080
# open http://localhost:8080
```

Spec: anime feel · faces left · three legs · red eye · black field.
