# Create project repos (no terminal)

The hub expects one repo per project. Create each empty repo on GitHub, then upload files through the website.

## Steps (repeat for each repo)

1. Go to [github.com/new](https://github.com/new)
2. Owner: **karasu-kai**
3. Repository name: see table below
4. Public
5. Check **Add a README file**
6. Click **Create repository**
7. Click **Add file → Upload files** and drop your project code
8. Commit
